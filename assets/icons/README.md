# App Icons

These are small-size derivatives of `../concepts/logos/v7/04-wide-interlock.svg`. The original VC geometry is preserved, tightly framed, and rendered with brighter blue, green, and red on transparent canvases. No background shape is added.

- `app-icon.svg` / `app-icon.png`: transparent 1024px app icon
- `favicon.png`: 256px source for Expo's browser-tab icon
- `adaptive-icon.svg` / `adaptive-icon.png`: transparent 1024px Android foreground with safe-zone padding; `app.json` also requests a transparent background

Edit the SVG sources and export the matching PNGs when changing these derivatives. Keep the original concept logo intact.
